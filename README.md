## 🚀 How to Install (Manual Installation)

Since this extension is not published to Chrome Web Store, you can install it manually on any Chromium-based browser (Chrome, Edge) by following these steps:

1. **Download the Code:**
   - Click the green **Code** button at the top of this page.
   - Select **Download ZIP**.
   - Extract the ZIP file to a folder on your computer.

2. **Open Extensions Page:**
   - Open Chrome and type `chrome://extensions/` in the address bar (or `edge://extensions/` for Microsoft Edge).

3. **Enable Developer Mode:**
   - In the top-right corner, switch the **Developer mode** toggle to **ON**.

4. **Load the Extension:**
   - Click the **Load unpacked** button that appears in the top-left.
   - Select the folder where you extracted the files (the folder containing `manifest.json`).

5. **Start LeetCoding:**
   - Pin the extension to your toolbar for easy access to your stats and custom audio settings!
